Einträge des Spielleiters versiegeln

Läuft nur hier im Browser, nichts wird verschickt. Eingabe: eine Liste wie in gm-entries.example.json (id, title, text, optional code). Fehlt ein Code, wird ein gut sprechbarer erzeugt. Heraus kommen zwei Dateien: Spielerdatei (Titel und Text verschlüsselt, im Zauberbuch-Generator unter „Heute vorbereitet → Andacht → Einträge importieren“) und Spickzettel (Kennung, Titel, Code – nur für dich).
